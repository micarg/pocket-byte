# Pocket Byte

Φορητή κονσόλα στον browser για παιχνίδια Game Boy (.gb) και Game Boy Color (.gbc). Εγκαθίσταται στο κινητό σαν εφαρμογή και δουλεύει και χωρίς ίντερνετ.

**Παίξε:** https://micarg.github.io/pocket-byte/

## Εγκατάσταση στο κινητό
- **iPhone (Safari):** Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
- **Android (Chrome):** μενού ⋮ → «Εγκατάσταση εφαρμογής» ή «Προσθήκη στην αρχική οθόνη».

## Παιχνίδια που περιλαμβάνονται
Δωρεάν παιχνίδια ανοιχτού κώδικα, με τις άδειές τους:
- [Libbet and the Magic Floor](https://github.com/pinobatch/libbet) – Damian Yerrick, άδεια zlib
- [Geometrix](https://github.com/AntonioND/geometrix) – Antonio Niño Díaz, GPLv3
- [µCity](https://github.com/AntonioND/ucity) – Antonio Niño Díaz, GPLv3
- [2048-gb](https://github.com/Sanqui/2048-gb) – Sanqui, άδεια zlib (χτισμένο με σύγχρονο RGBDS)

Ο πηγαίος κώδικας κάθε παιχνιδιού βρίσκεται στους παραπάνω συνδέσμους.

## Game Boy Advance, Genesis, Nintendo 64 και arcade
Τα παιχνίδια Game Boy Advance, Sega Genesis / Mega Drive, Nintendo 64 και arcade τρέχουν με το [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) (GPLv3), που φορτώνεται από το CDN του την πρώτη φορά και μετά μένει αποθηκευμένο στη συσκευή.
